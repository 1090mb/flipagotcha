# Flipagotcha Wiki

Welcome to the **Flipagotcha** wiki! This is your complete guide to building, installing, and using the Flipagotcha app for Flipper Zero.

## 🎯 What is Flipagotcha?

Flipagotcha is a Pwnagotchi-style application for the Flipper Zero that displays an animated face on the screen and integrates with ESP32 Marauder firmware for WiFi scanning, packet capture, and security research capabilities.

### Key Features
- 🎭 **Animated Face**: Minimalist animated face with blinking eyes and expressions
- 📡 **WiFi Scanning**: Real-time WiFi network scanning via ESP32 Marauder
- 🤝 **Handshake Capture**: WPA/WPA2/WPA3 handshake capture capabilities
- 📦 **Packet Capture**: Raw 802.11 packet capture and storage
- 🎮 **Interactive Controls**: Button-based interface for all features
- 💾 **Data Storage**: Save captured packets to SD card
- 🔄 **Demo Mode**: Works without ESP32 hardware for testing
